# VFX MUSIC VAULT

Responsive neon-style music discovery web app powered by SOURAJIT VFX.

## Features
- Search tracks, artists, and moods
- Responsive mobile and desktop UI
- Audio controls: play/pause, next/previous, seek, volume, shuffle and repeat
- Liked songs and play history stored in browser localStorage

## Hosting
- GitHub Pages: serve `index.html`, `styles.css`, and `app.js` from the repository root.
- Render/Railway/Koyeb: Node.js app, start command `npm start`.
- InfinityFree: upload the static files to `htdocs`; it does not run a persistent Node.js server.

Audio links are sample/demo URLs. Replace with music you own or are licensed to stream before production use.
